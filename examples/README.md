# Payload examples

Examples of using Payload in different situations, as the `payload-examples` package of this workspace. All of these examples are compiled and run as part of the test suite (`npm test`).

* [hello](./src/Payload/Examples/Hello): A simple hello world
* [basic](./src/Payload/Examples/Basic): A larger example showing hierarchical routes
* [files](./src/Payload/Examples/Files): Serving files
* [movies](./src/Payload/Examples/Movies): A larger example based on the [Movie Database API](https://developers.themoviedb.org)
* [GitHub client](./src/Payload/Examples/ClientGitHub): Example client for the GitHub API
